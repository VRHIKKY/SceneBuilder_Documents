# VketCloudの仕様制限

## ポリゴン

ワールドに配置するモデルは、目安として合計80万トライアングル以下にしてください。<br>
80万トライアングルより多くワールドに配置すると、スマートフォンでの動作に支障をきたす場合があります<br>
プレイヤーのアバターのトライアングル数はこの制限には含みません。

## テクスチャ

Vket Cloudでは以下のフォーマットのテクスチャ画像が使用できます。<br>

- 大きさが2048x2048以下のpng形式のファイル
- ２の累乗サイズの正方形（2048x2048,1024x1024,512x512等）または2の累乗サイズの長方形
- ビット深度は24bitまたは32bit
- png換算で80MB以下
  - 80MBより多くワールドに配置すると、スマートフォンでの動作に支障をきたす場合があります<br>
- 拡張子は小文字の".png"しか受け付けません。

## コライダー

- プレイヤーの衝突判定用はBoxColliderとMeshColliderのみ対応しています。<br>
  MeshColliderは処理に非常に負荷がかかるため使用は必要最低限にしてください。<br>
  BoxColliderはTPSモード時にプレイヤーアバターとカメラの間に位置するオブジェクトによって遮断されるのを防ぐためにも利用しているため、天井など移動出来ない場所でも設定して下さい。MeshColliderの書き出し方法については[こちら](./Reformatting3DModels/ExportingHEOUsingVketCloudSDK.md)をご覧ください。
- Scene Builderで読み込んだglbファイルはのコライダーは、バウンディングボックス（モデルにぴったりと被さる透明の箱のようなイメージ）として設定されます。現バージョンでは、MeshColliderへの変換は対応していないため、細かくモデルを編集するか、heoフォーマットでの書き出しを行ってください。heoフォーマットの書き出し方法については[こちら](./Reformatting3DModels/ExportingHEOUsingVketCloudSDK.md)をご覧ください。

## スカイボックス

- スカイボックスは非対応です。使わない、もしくは天球などで空を作成します。

## スケール

- マイナススケールにすると、メッシュが裏返しになり法線が反転します。ワールドでは内側にメッシュが描画されるためご注意ください。<br>
- 意図的でないマイナススケールのオブジェクトについては設定の修正をおすすめします。-

## オーディオファイルのフォーマット

オーディオファイルを使用する場合、以下のフォーマットに従ってください。

| 名称 | 詳細 |
| ---- | ---- |
| ファイル形式 | mp3 |
| サンプリングレート | 44100 Hz |
| ビットレート | 160 kbps |

!!! note caution
    BGMは以下の点に注意が必要です。

    - 動画再生時には、動画の音声が優先されます。
    - 距離減衰には対応していません。
